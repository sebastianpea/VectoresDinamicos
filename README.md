# Tarea 1.2 – Memoria estática vs. memoria dinámica (C#, Windows Forms, .NET 8)

Solución de Visual Studio 2022

- **VectoresDinamicos**: genera y redimensiona arreglos en tiempo de ejecución,
  muestra el crecimiento de List<int> y compara dos estrategias de crecimiento.

## Ejecución
1. Abrir `VectoresDinamicos.sln` en Visual Studio 2022.
2. Clic derecho en el proyecto → Establecer como proyecto de inicio.
3. F5 (o Ctrl+F5 en Release para medir tiempos).
